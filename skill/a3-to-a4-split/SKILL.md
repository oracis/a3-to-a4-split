# A3 双拼版拆成 A4

## 这个技能解决什么

排试卷、讲义、教辅时，常把两张 A4 并排拼成一张 A3 横向打印。要拆回单页 A4 时，
绝大多数做法都会出错：**改纸张、改分栏会让 Word 重排错位；按页面中线切会把字切到隔壁页**。
本技能用「读 PDF 内容流 → 找两栏真实边框 → 在缝隙中点下刀」的方式切分，
字体、公式、图片全部保持矢量，不栅格化。

## 一条命令开始

```bash
python scripts/split_word.py <输入.docx 或 输入.pdf> [输出.pdf]
```

默认输出到同目录的 `xxx-可打印A4.pdf`。内部自动串完四步，无需手动先转 PDF：

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| 1 | 清掉 Word 里的图案/网点底纹（`w:shd`） | 10% 网点在屏幕上与笔画叠成浅灰，看着就是「文字发虚、有重影」 |
| 2 | 调本机 Word 导出 PDF（300 PPI、不压图） | docx 里没有「页」这个对象，分页是 Word 排版算出来的，必须先让它排一次版 |
| 3 | 把公式位图的透明蒙版（SMask）预合成到白底 | 部分阅读器做 alpha 合成会在笔画外产生灰色光晕 |
| 4 | 按两栏真实边框切 4 页 A4 | 见下方「切口怎么定」 |

第 1、3 步都只写临时文件，**不改用户的原始文档**。

## 切口怎么定（核心）

A3 宽 1190.64pt，正中间是 595.32pt，但左右两栏通常**不对称**。实测过的一份：

| | 左栏内容框 | 右栏内容框 |
|---|---|---|
| 第 1 张 A3 | 84.7 ~ **619.4** | 624.1 ~ 1167.0 |
| 第 2 张 A3 | 36.8 ~ **617.2** | 622.0 ~ 1171.7 |

左栏一直写到 619，中线右侧还有 24pt 属于左页。按中线切，`…需要药粉多少千` 的「千」
就跑到下一页，上一页读成「…需要药粉多少 克？」——这是最典型的翻车方式。

`split_a3.py` 的做法：
1. 从内容流里挑出「一栏那么大」的 `re` 矩形（宽 150~700、高 250~900），按 x 中心聚类；
2. 最大间隙处一分为二，即两栏；
3. 切口 = **左栏右边框与右栏左边框的中点**，两页各自保留自己的边框；
4. 每栏以自身内容框为中心、按 A4 宽 595.32 定 MediaBox，原点归零；
5. 内容流先 `1 0 0 1 -wl 0 cm` 平移、**再** `re W n` 裁剪（顺序反了会把内容左半截裁掉）。

单栏 A3（普通横向文书）识别不到双栏时，自动退回中线切分。

## 常用选项

```bash
python scripts/split_word.py 试卷.docx 结果.pdf --no-clean    # 不清网点底纹
python scripts/split_word.py 已有.pdf 结果.pdf                # 已是 PDF 就跳过 Word 导出
python scripts/split_a3.py in.pdf out.pdf --keep-marks        # 保留页顶黑色裁切标记
python scripts/split_a3.py in.pdf out.pdf --keep-strip        # 保留左侧姓名学号竖条
python scripts/split_a3.py in.pdf out.pdf --mark-size 28.2x14.1  # 只删这个尺寸的标记
```

## 验收（必做，不要跳过）

切分错位是**肉眼才看得出来**的问题，文件大小和页数都正常。生成后至少做两件事：

```bash
# 1. 结构自检：xref 偏移、流长度、页树、页面框是否 595.32x842.04 且原点归零
python scripts/check_pdf.py 结果.pdf

# 2. 渲染成图并抽文本坐标（需要 Node 22+ 与 Chrome/Edge）
node scripts/render_pages.mjs 结果.pdf ./预览 --scale 2
```

然后打开 `./预览/p1.png …` 逐页确认，重点看：

- **页边有没有孤立单字**（上一页末尾被切过来的字）；
- 跨行的词是否完整，例如「千克」被拆成上一页「千」、下一页「克？」——这种在排版上合法，
  但若「千」落在页边空白外或整行缺字，就是切错了；
- 每页是否只有自己的边框线，没有隔壁页的半截边框；
- 页顶/页脚有没有残留黑块。

`text.json` 里每页有 `[{t, x, y}]`，x/y 是 PDF 用户坐标（左下原点），
可直接定位某段文字落在哪一页、x 是否超出 `[0, 595.32]`。
超出页面范围的文本项如果落在裁剪框外，是不可见的，属正常。

## 脚本清单

| 脚本 | 作用 |
|---|---|
| `split_word.py` | **主入口**：docx/doc/pdf → 4 页 A4 可打印 PDF，串起下面四步 |
| `split_a3.py` | 核心切分：识别两栏、切口、裁剪、清黑块、裁姓名学号竖条、页面框归零 |
| `clean_shading.py` | 删 docx 里的 `w:shd` 底纹（治发虚/重影），其余部件原样保留 |
| `flatten_smask.py` | PDF 透明蒙版预合成到白底（治灰色光晕） |
| `check_pdf.py` | 结构自检 |
| `render_pages.mjs` + `render.html` | 渲染 PNG + 抽文本坐标，供视觉验收 |

全部只依赖 Python 标准库；渲染脚本需要 Node 22+（内置 WebSocket）和本机 Chrome/Edge，
pdf.js 默认走 CDN，离线环境用 `--pdfjs <本地 pdf.min.js>` 指定。

## 已知限制

- 输入须是 A3 横向、两栏左右并排。竖排、单栏通版只能走中线切分。
- Word 导出依赖本机装有 Word 或 WPS；缺失时第 2 步会明确报错，不会静默产出坏文件。
- 输出是**打印用 PDF**，不是可编辑的 A4 Word。要可编辑版必须重新排版，属另一件事。
- 不能靠删 docx 里的浮动对象来「去掉姓名学号」——Word 会重排，后面的页会整体塌掉。
  正确做法是在 PDF 层裁（`split_a3.py` 已内置）。
